# Health-care
Project Overview  
“Kidney Health Care App is a Streamlit-based machine learning tool that predicts Chronic Kidney Disease (CKD) risk using patient health parameters. It helps visualize data trends and supports early detection.”

Features

Input form for patient parameters (age, blood pressure, blood sugar, albumin, etc.)

CKD risk prediction using trained ML models

Interactive charts for feature importance and data distribution

Clean UI with easy deployment on Streamlit Cloud

Tech Stack  
Python, Pandas, Scikit-learn, Streamlit, Matplotlib/Seaborn
